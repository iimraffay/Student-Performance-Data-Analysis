# Student Performance Data Analysis

This project is part of my Data Science Internship at Codomax.

For this project, I worked with a real world Student Performance dataset from the UCI Machine Learning Repository. The purpose was to explore student information, analyze academic results, and understand different patterns in the data.

## Project Overview

The analysis focuses on student grades, study time, past failures, and school absences. I used Python to explore the dataset and understand how these factors are related to student performance.

## What I Worked On

- Loaded and explored a real world dataset
- Checked the dataset for missing values and duplicates
- Analyzed student grades
- Compared performance across different grading periods
- Examined study time and past failures
- Explored the relationship between absences and final grades
- Created charts to present the results
- Used correlation analysis to explore relationships between numerical variables

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The dataset was obtained from the UCI Machine Learning Repository.

It contains student information and academic records from two Portuguese secondary schools.

Dataset Source: https://archive.ics.uci.edu/dataset/320/student+performance

Original dataset by Paulo Cortez and Alice Silva.

## Project Files

The repository contains the Google Colab notebook, visualizations, and the analyzed dataset.

Through this project, I got more practice working with real world datasets, exploring data, creating visualizations, and finding useful information from the results.

It also helped me understand how Python can be used to analyze data and present findings in a clear way.
